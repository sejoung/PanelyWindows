# 제품 범위와 기능 계약

## 제품 성격

Panely는 로컬 만화·이미지를 읽는 단일 리더 창 앱이다. 다크 테마를 고정하고 페이지를 최대한 넓게 보여준다. 툴바와 페이지 슬라이더는 필요할 때 떠오르며, 라이브러리는 고정하거나 왼쪽에서 잠깐 펼칠 수 있다. 원본 파일은 읽기 전용으로 다루고 번역은 표시 레이어와 별도 내보내기로 제공한다.

Windows 결정: Windows 11 x64를 1차 지원 대상으로 잡고 ARM64는 동일 검수 후 추가한다. 창의 최소 **콘텐츠 영역**은 800×600 DIP. 리더 1개와 설정·작업 보조 창을 사용한다. 탐색기에서 여러 번 파일을 열어도 실행 중인 리더로 전달한다. 기본 기능에 계정·서버·구독을 요구하지 않는다.

## 최초 실행 기본값

| 설정 | 값 | 범위 |
|---|---|---|
| 레이아웃 / 방향 / 맞춤 | single / leftToRight / fitScreen | 전역 + 시리즈별 override |
| 라이브러리 고정 | true | 영속 |
| 툴바 고정 / 미리보기 표시 | false / false | 영속 |
| 자동 재맞춤 | true (크기 잠금 해제) | 영속 |
| 표지 한 장 | false | 전역 영속, double에서만 적용 |
| 휠 페이지 넘김 | true | 전역 영속, vertical 제외 |
| 마지막 폴더 복원 | true | 전역 영속 |
| 인터페이스 언어 | system | en/ko 외에는 en |
| 번역 보조 | false | 실험 설정 |
| 번역 모드 / 말투 맞춤 | fast / true | 실제 공급자 능력에 따라 설명 |
| 번역 대상 언어 | null | 인터페이스 언어, 지원하지 않으면 en |
| 번역 레이어 표시 | true | 번역 기능과 별도 상태 |
| 로그 수준 | info | 이후 기록에만 적용 |
| 내보내기 기본 형식 / 미번역 정책 | cbz / translateFirst | 이후 선택 기억 |

새 책을 열어도 UI 고정 상태를 초기화하지 않는다. 시리즈 설정은 `override ?? global`로 결정한다. 사용자가 방향·레이아웃·맞춤을 바꾸면 현재 시리즈 override와 전역 기본값을 함께 갱신한다. 줌은 세션 메모리만 유지한다.

## 화면과 상태

| 화면 | 내용과 행동 |
|---|---|
| 빈 리더 | near-black 바탕, 파일 열기 안내. 빈 라이브러리에도 열기 버튼 |
| 읽는 중 | 뷰어, 선택적 양쪽 패널, 떠 있는 툴바/슬라이더, 페이지·권 카운터 |
| 로딩 | 앱 위 반투명 차폐, 스피너와 Opening/Extracting/Loading/Building 단계 |
| 소스 변경 | 상단 배너의 다시 불러오기·닫기. 읽는 위치를 자동 이동하지 않음 |
| 오류 | 상단에 원인·재시도/열기/목록 제거 중 해당 액션. 깨진 한 쪽은 타일 유지 |
| 권 경계 | 위 Previous, 아래 Up next. 마지막 권이면 다음 권 카드는 없음 |
| 번역 중 | 초기 준비/진행/남은 시간 pill, 말풍선별 대기·완료, 슬라이더 번역 마크 |
| 번역 편집 | 페이지 위 편집 바, 수정 연필, 숨긴 풍선 점선, 드래그 영역 추가 |
| 작업 창 | 현재/다른 책 번역, 내보내기, 실패 작업, 완료 내보내기 이력 |
| 설정 창 | 5개 탭, 영속 선택·용량·삭제/내보내기 결과 |

알림 우선순위는 소스 변경 → 리더 오류 → 권 이동 안내 → 번역 안내다. 로딩 중 오류/안내를 중첩해 클릭을 막지 않는다. 텍스트 입력·팝오버·모달에서 읽기 단축키가 타이핑을 가로채지 않게 한다.

## 포함하지 않는 새 기능

PDF·EPUB·7z, 클라우드 동기화, 원격 라이브러리, 다중 리더 탭, 계정, 자동 업데이트 서비스는 현재 동등성 범위에 없다. 드래그 앤 드롭은 원본 설명/주석에 언급되지만 현재 화면의 수신 처리는 확인되지 않았다. Windows에서는 파일/폴더 드롭을 같은 열기 파이프라인에 연결하는 **추가 결정**으로 구현해도 된다. 전체 화면은 Windows 창 명령으로 제공하되 읽기 상태를 별도로 만들지 않는다.
