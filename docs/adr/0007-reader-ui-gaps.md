# ADR 0007: 원본에 있던 기능 진입점을 되살리고, 슬라이더의 번역 완료 표시는 뺀다

- 상태: 채택
- 날짜: 2026-10-19
- 관련 코드: `PageTrack.OnRender`(`Controls/PageSlider.cs`), `TranslationFeature.BuildLanguageMenuItems`, `TranslationFeature.ExitWarning`, `MainWindow.OnClosing`, `AiChatSheet`, `EditBar.Refresh`, `TranslationPanel.BuildBookSection`, `LibrarySidebar.UpdateHeader`

## 배경

실제 앱을 써 보니 두 가지 문제가 있었다.

- 하단 페이지 슬라이더 아래에 accent색 선이 또 깔렸다. 번역이 끝난 쪽을 표시하는 선(높이 2)이었다. 첫 포팅 명세가 "번역 완료 쪽은 썸네일 배지와 슬라이더 마크"로 정한 것이다. 그런데 읽은 위치를 채우는 색과 같아서, 책을 다 번역하면 슬라이더 전체가 파랗게 보였다. 어디까지 읽었는지 구분할 수 없었다.
- 툴바 언어 메뉴에 "AI 채팅으로 다듬기"가 없었다. 기능은 구현되어 있었지만 페이지 우클릭과 번역 패널에서만 열 수 있었다.

두 번째 문제를 보고 같은 종류의 누락을 찾았다. 원본 문구 카탈로그에 있는데 Windows 코드가 쓰지 않는 key 168개를 뽑았다. 그중 macOS 시스템 메뉴(맞춤법·받아쓰기·창 배치 등), macOS 단축키가 붙은 tooltip, Apple Intelligence, 샌드박스 폴더 권한 문구를 빼고 남은 것을 코드와 대조했다.

## 결정

1. 슬라이더에서 번역 완료 표시를 뺀다. 번역된 쪽은 썸네일 배지로만 보여 준다. 슬라이더의 accent색은 읽은 위치만 뜻한다.
2. 툴바 언어 메뉴를 원본 순서로 맞춘다.
   - 보기: 원본, 번역된 언어(완료 쪽 수 포함)
   - 다른 언어로 번역 ▸
   - 이 페이지 다시 번역, AI 채팅으로 다듬기…, 번역 패널…, 말풍선 편집
   - 번역본 내보내기…
   - 작업: 원본에는 없지만 Windows 메뉴에 있던 항목이라 맨 아래에 남긴다.
3. 원본에 있던 다음 진입점·안내를 되살린다.

   | 원본 | Windows에서 빠져 있던 것 | 지금 |
   |---|---|---|
   | 번역·내보내기 중 종료 확인 | 확인 없이 종료되고 작업이 사라졌다 | 실행 중이거나 대기 중인 작업이 있으면 "Panely를 종료할까요?"를 묻는다 |
   | AI 채팅 창의 말풍선 수와 파일 형식 안내 | 없었다 | 범위를 바꿀 때마다 담길 말풍선 수를 보여 주고, 저장 버튼 아래에 줄 형식을 적는다 |
   | 편집 바의 고친·숨긴 말풍선 수 | 없었다 | 제목 옆에 "고친 말풍선 N개 · 숨김 N개". 숨긴 풍선이 있으면 점선 윤곽을 눌러 되살린다는 안내로 바꾼다 |
   | 시리즈 자동 번역이 함께 번역할 권 | 없었다 | 토글 아래에 "함께 번역할 권: …"(3권까지, 나머지는 개수) |
   | 라이브러리 폴더 변경 | 파일 › 폴더 열기로만 바꿀 수 있었다(책도 함께 열림) | 라이브러리 헤더 우클릭 › "라이브러리 폴더 변경…" |

4. 종료 확인 문구는 원본과 다르게 쓴다. Windows는 작업 큐를 앱 종료 때 버리고 완료한 쪽만 캐시에 남기므로, "다시 시작하면 나머지가 이어진다" 대신 "다시 번역하면 멈춘 곳부터 이어진다"로 쓴다.
5. 다음은 일부러 넣지 않는다.
   - macOS 시스템 메뉴: Windows에 해당 기능이 없다.
   - Apple Intelligence·macOS 버전 조건, 폴더 접근 허용(샌드박스): Windows에 해당 조건이 없다.
   - 말투 맞춤 진행 표시: 기능이 없다(ADR 0004).

## 결과

- 슬라이더만 보고는 어느 쪽이 번역됐는지 알 수 없다. 썸네일 패널을 켜야 보인다.
- 번역 중에 창을 닫으면 확인 창이 한 번 뜬다. Windows 로그오프 때도 뜰 수 있다.
- AI 채팅 창은 범위를 바꿀 때마다 그 범위의 캐시를 읽어 말풍선 수를 센다. 책 전체(약 300쪽)에서도 캐시 파일만 읽는다.
- 앞으로 원본 기능이 빠졌는지 볼 때는, 카탈로그에서 쓰이지 않는 key를 다시 뽑아 이 표와 대조한다(ADR 0006).
