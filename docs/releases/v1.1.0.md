Panely for Windows 1.1 replaces the translation model. Translation now uses Gemma 4 E2B, which reads balloons together with the lines before them and keeps each speaker's speech level. It runs on the GPU through Vulkan. This release also fixes language pack download progress and adds a user guide.

**English** · [한국어](#한국어)

## Download

| File | For |
|---|---|
| `Panely-1.1.0-win-x64.zip` | Most Windows PCs (Intel and AMD) |
| `Panely-1.1.0-win-arm64.zip` | Windows on ARM. **Not run on an ARM device yet**, and translation runs on the CPU only. Please report what you see |

Extract the ZIP to a folder and run `Panely.exe`. No installer, administrator rights or .NET install are needed. Checksums are in `SHA256SUMS.txt`.

**Updating from 1.0.x**: close Panely and replace the folder's contents with this ZIP. Your library, reading positions and edits are kept. Translations made with 1.0.x need translating again (see below).

The app isn't code-signed, so SmartScreen may say "Windows protected your PC" on first launch: choose **More info › Run anyway**.

## Changed: a new translation model

- **Gemma 4 E2B replaces M2M100.** The **Fast** and **Accurate** options are gone; there is one model.
  - It translates 16 balloons at a time together with the six lines translated just before them, so it keeps each speaker's speech level (polite or casual) and names.
  - The separate **Match Speech Level** option is gone; matching speech level is now part of every translation.
  - Simplified and Traditional Chinese can now be translated into each other.
- **It runs on the GPU through Vulkan** (most NVIDIA, AMD and Intel GPUs) inside the app, using [llama.cpp](https://github.com/ggml-org/llama.cpp) through LLamaSharp. Without a usable GPU, it runs on the CPU.
- **Measured** on a 298-page Japanese webtoon with 146 balloons (Core i7-13700K, RTX 4070 Ti SUPER):

  | | Whole book | First translation shown |
  |---|---|---|
  | 1.0 Fast (M2M100) | 83 s | 10.6 s |
  | 1.0 Accurate (M2M100) | 90 s | 13.6 s |
  | **1.1 Gemma 4 E2B, GPU** | **58 s** | **9.5 s** |
  | 1.1 Gemma 4 E2B, CPU only | 325 s | 14.7 s |

  In the developer's side-by-side review, Gemma read much better than both M2M100 modes. That's one person's judgment, not a check against a reference set.
- **The language pack is now 3.1 GB** (about 3.4 GB in total for Japanese books). The old M2M100 packs (up to about 2.9 GB) are deleted automatically when Panely starts.
- **Books translated with 1.0.x need translating again**, because the results came from a different model. Balloons you edited keep your edits.
- The download ZIP is larger, because it now includes llama.cpp (about 75 MB uncompressed on x64).

## Fixed

- **Language pack download progress now updates as it downloads.** In **Settings › Experimental**, the percentage only changed when you switched tabs and came back.
- **Downloading language packs now shows one clear progress.** The packs download as one job: the translation panel shows which pack is downloading and the overall size (for example "1.1 GB of 3.1 GB"), and the bar no longer jumps back to 0 for each pack. Before, the panel could look idle between packs and show the download button again.
- **The download stays visible when the panel is closed.** "Downloading language packs · 1.1 GB of 3.1 GB" shows at the bottom of the viewer.
- **Translation continues after the download without restarting.** A translation that was waiting for language packs (for example a series set to translate automatically, or packs downloaded from Settings) now starts by itself once the packs are installed. Before, it stayed paused until you restarted Panely.
- **Detecting the book's language no longer fails when the text recognition pack is missing.** The panel offers the download first, and detection runs after it. Before, it stopped with a message about Windows text recognition settings.

## For developers

- Korean output from `dotnet` (build, test and verify logs) is no longer garbled when you run `build.cmd`, `verify.cmd`, `release.cmd`, `install-local.cmd` or `uninstall-local.cmd` in a Korean console.
- `tools/manual-screenshots.ps1` regenerates the user guide's screenshots from a synthetic demo comic.
- Set `PANELY_TEST_LLM_MODEL` to a downloaded GGUF to run the real-model translation test. The decision is recorded in [ADR 0008](https://github.com/sejoung/PanelyWindows/blob/main/docs/adr/0008-gemma-translator.md).

## Known limitations

- Translation is experimental and makes mistakes, especially when text recognition misreads the original. Quality hasn't been checked against a golden set.
- **Without a usable GPU, translation is several times slower** (see the table above). Windows on ARM always translates on the CPU.
- Translating uses several GB of memory (up to about 7.5 GB in the measurement above, including balloon detection).
- In the AI chat window, the prompt shows a balloon count of 0 until you click **Save as Text File…**. Save the file first, then copy the prompt.
- Not tested yet: Windows on ARM, 125/150% and mixed-DPI setups, high-contrast mode.
- Translation jobs in progress are lost when you quit (finished pages are kept).

## 한국어

Panely Windows 1.1은 번역 모델을 바꿉니다. 이제 Gemma 4 E2B로 번역하며, 말풍선을 바로 앞 대사와 함께 읽어 인물마다 말투(존댓말·반말)를 이어 갑니다. GPU에서는 Vulkan으로 돕니다. 언어팩 다운로드 진행률 표시도 고쳤고, 사용 설명서를 추가했습니다.

### 내려받기

| 파일 | 대상 |
|---|---|
| `Panely-1.1.0-win-x64.zip` | 대부분의 Windows PC(Intel·AMD) |
| `Panely-1.1.0-win-arm64.zip` | ARM 기반 Windows. **실제 ARM 기기에서는 아직 실행해 보지 않았고**, 번역은 CPU로만 돕니다. 실행 결과를 알려 주세요 |

ZIP을 폴더에 풀고 `Panely.exe`를 실행합니다. 설치 프로그램, 관리자 권한, .NET 설치가 필요 없습니다. 체크섬은 `SHA256SUMS.txt`에 있습니다.

**1.0.x에서 업데이트**: Panely를 닫고 폴더 내용을 이 ZIP으로 바꿉니다. 라이브러리, 읽던 위치, 고친 내용은 그대로 남습니다. 1.0.x에서 번역한 책은 다시 번역해야 합니다(아래 참고).

코드 서명이 없어 처음 실행할 때 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다. **추가 정보 › 실행**을 누르세요.

### 바뀐 것: 새 번역 모델

- **M2M100 대신 Gemma 4 E2B로 번역합니다.** **빠르게**·**정확하게** 선택이 없어지고 모델이 하나가 됐습니다.
  - 말풍선 16개를 직전에 번역한 6줄과 함께 번역해, 인물마다 말투(존댓말·반말)와 이름을 이어 갑니다.
  - 따로 있던 **말투 맞추기** 설정은 없어지고, 말투 맞춤이 모든 번역에 들어갑니다.
  - 중국어 간체와 번체 사이도 번역할 수 있습니다.
- **GPU에서는 Vulkan으로 돕니다**(대부분의 NVIDIA·AMD·Intel GPU). LLamaSharp로 [llama.cpp](https://github.com/ggml-org/llama.cpp)를 앱 안에서 실행합니다. 쓸 수 있는 GPU가 없으면 CPU로 돕니다.
- **측정**(298쪽 일본어 웹툰, 말풍선 146개, Core i7-13700K, RTX 4070 Ti SUPER):

  | | 책 전체 | 첫 번역 표시 |
  |---|---|---|
  | 1.0 빠르게 (M2M100) | 83초 | 10.6초 |
  | 1.0 정확하게 (M2M100) | 90초 | 13.6초 |
  | **1.1 Gemma 4 E2B, GPU** | **58초** | **9.5초** |
  | 1.1 Gemma 4 E2B, CPU만 | 325초 | 14.7초 |

  개발자가 나란히 비교해 본 평가로는 Gemma가 M2M100 두 방식보다 훨씬 나았습니다. 한 사람의 평가이며 기준 번역으로 검수한 결과는 아닙니다.
- **언어팩은 3.1GB입니다**(일본어 책 기준 합계 약 3.4GB). 예전 M2M100 팩(최대 약 2.9GB)은 Panely를 시작할 때 자동으로 지웁니다.
- **1.0.x에서 번역한 책은 다시 번역해야 합니다.** 다른 모델의 결과이기 때문입니다. 직접 고친 말풍선은 남습니다.
- llama.cpp가 들어가 다운로드 ZIP이 커졌습니다(x64 기준 압축 해제 시 약 75MB).

### 고친 것

- **언어팩 다운로드 진행률이 받는 동안 바로 갱신됩니다.** 전에는 **설정 › 실험적 기능**에서 다른 탭에 갔다 와야 퍼센트가 바뀌었습니다.
- **언어팩 다운로드 진행이 하나로 보입니다.** 여러 팩을 하나의 다운로드로 받으며, 번역 패널에 지금 받는 팩과 전체 크기(예: "1.1 GB / 3.1 GB")가 표시되고, 팩이 바뀔 때 막대가 0으로 돌아가지 않습니다. 전에는 팩 사이에 패널이 멈춘 것처럼 보이고 다운로드 버튼이 다시 나타날 수 있었습니다.
- **패널을 닫아도 다운로드가 보입니다.** 뷰어 아래쪽에 "언어팩 받는 중 · 1.1 GB / 3.1 GB"가 표시됩니다.
- **언어팩을 받은 뒤 다시 시작하지 않아도 번역이 이어집니다.** 언어팩이 없어 멈춰 있던 번역(시리즈 자동 번역, 설정에서 받은 경우 등)이 팩 설치가 끝나면 저절로 시작합니다. 전에는 Panely를 다시 시작해야 했습니다.
- **글자 인식 팩이 없을 때 책 언어 감지가 실패하지 않습니다.** 패널이 먼저 언어팩 다운로드를 안내하고, 받은 뒤 감지합니다. 전에는 Windows 글자 인식 설정 안내와 함께 멈췄습니다.

### 알려진 제약

- 번역은 실험 기능이라 틀릴 때가 있고, 특히 글자 인식이 원문을 잘못 읽으면 번역도 틀립니다. 골든 세트로 품질을 검수하지 않았습니다.
- **쓸 수 있는 GPU가 없으면 번역이 몇 배 느립니다**(위 표 참고). ARM 기반 Windows는 항상 CPU로 번역합니다.
- 번역하는 동안 메모리를 수 GB 씁니다(위 측정에서 최대 약 7.5GB, 말풍선 탐지 포함).
- AI 채팅 창의 안내문은 **텍스트 파일로 저장…**을 누르기 전에는 말풍선 수를 0으로 표시합니다. 파일을 먼저 저장한 뒤 안내문을 복사하세요.
- 아직 확인하지 않은 환경: ARM 기반 Windows, 125/150% 및 혼합 DPI, 고대비 모드.
- 진행 중인 번역 작업은 앱을 종료하면 사라집니다(완료한 쪽은 남습니다).
