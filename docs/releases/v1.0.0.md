First public release of Panely for Windows: a fast, offline comic and manga reader with experimental on-device balloon translation.

**English** · [한국어](#한국어)

## Download

| File | For |
|---|---|
| `Panely-1.0.0-win-x64.zip` | Most Windows PCs (Intel and AMD) |
| `Panely-1.0.0-win-arm64.zip` | Windows on ARM. **Not run on an ARM device yet** — please report what you see |

Extract the ZIP to a folder and run `Panely.exe`. No installer, administrator rights or .NET install are needed. Checksums are in `SHA256SUMS.txt`.

The app isn't code-signed, so SmartScreen may say "Windows protected your PC" on first launch: choose **More info › Run anyway**.

## Highlights

- Single page, two-page spread and vertical webtoon scroll; right-to-left reading for manga
- Folders, ZIP/CBZ and RAR/CBR (RAR4, RAR5, solid); JPEG, PNG, WebP, GIF, HEIC/HEIF, BMP, TIFF
- Library tree, continue reading, recents, favorites and page bookmarks
- English and Korean UI, dark theme, single instance, optional "Open with Panely"
- Experimental translation that runs entirely on your PC (Japanese, Chinese, English, Korean sources), with balloon editing and CBZ/ZIP/folder export

## Known limitations

- Translation is experimental. The small M2M100 model often gets short lines and idioms wrong, and quality hasn't been checked against a golden set.
- The **Accurate** translation mode (fp32, 2.3 GB language pack) hasn't been tested; speed, memory use and quality are unknown. Use **Fast**.
- "Match Speech Level" isn't available on Windows yet.
- Not tested yet: Windows on ARM, 125/150% and mixed-DPI setups, high-contrast mode.
- Translation jobs in progress are lost when you quit (finished pages are kept).

| 파일 | 대상 |

ZIP을 폴더에 풀고 `Panely.exe`를 실행합니다. 설치 프로그램, 관리자 권한, .NET 설치가 필요 없습니다. 체크섬은 `SHA256SUMS.txt`에 있습니다.

코드 서명이 없어 처음 실행할 때 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다. **추가 정보 › 실행**을 누르세요.

### 주요 기능

- 한 쪽, 두 쪽 펼침, 웹툰용 세로 스크롤. 망가용 오른쪽→왼쪽 읽기
- 폴더, ZIP/CBZ, RAR/CBR(RAR4·RAR5·solid). JPEG, PNG, WebP, GIF, HEIC/HEIF, BMP, TIFF
- 라이브러리 트리, 이어보기, 최근 항목, 즐겨찾기, 쪽 북마크
- 영어·한국어 UI, 다크 테마, 단일 인스턴스, "Panely로 열기"(선택)
- PC 안에서만 도는 번역(실험 기능, 일본어·중국어·영어·한국어 원문). 말풍선 편집, CBZ/ZIP/폴더 내보내기

### 알려진 제약

- 번역은 실험 기능입니다. 작은 M2M100 모델이라 짧은 대사와 관용 표현을 자주 틀리며, 골든 세트로 품질을 검수하지 않았습니다.
- **정확하게** 번역 방식(fp32, 언어팩 2.3GB)은 검증하지 않았습니다. 속도·메모리·품질을 알 수 없으니 **빠르게**를 쓰세요.
- 말투 맞춤은 Windows에서 아직 쓸 수 없습니다.
- 아직 확인하지 않은 환경: ARM 기반 Windows, 125/150% 및 혼합 DPI, 고대비 모드.
- 진행 중인 번역 작업은 앱을 종료하면 사라집니다(완료한 쪽은 남습니다).
