Patch release for Panely for Windows 1.0. It fixes language pack download progress, records measurements for the Accurate translation mode, and adds a user guide.

**English** · [한국어](#한국어)

## Download

| File | For |
|---|---|
| `Panely-1.0.1-win-x64.zip` | Most Windows PCs (Intel and AMD) |
| `Panely-1.0.1-win-arm64.zip` | Windows on ARM. **Not run on an ARM device yet** — please report what you see |

Extract the ZIP to a folder and run `Panely.exe`. No installer, administrator rights or .NET install are needed. Checksums are in `SHA256SUMS.txt`.

**Updating from 1.0.0**: close Panely and replace the folder's contents with this ZIP. Your library, reading positions, edits and language packs are kept.

The app isn't code-signed, so SmartScreen may say "Windows protected your PC" on first launch: choose **More info › Run anyway**.

## Fixed

- **Language pack download progress now updates as it downloads.** In **Settings › Experimental**, the percentage only changed when you switched tabs and came back.
- **The translation panel shows the download while every pack downloads.** On a first install, the panel looked idle while the translation and balloon-detection packs downloaded (about 770 MB), and showed the download button again.

## Changed

- **Accurate translation mode has been measured.** On a 298-page Japanese webtoon with 146 balloons, it took about 7 seconds longer than Fast for the whole book and used about 2 GB more memory at peak (5.8 GB vs 3.5 GB). In a side-by-side review its translations read much better than Fast. That review is one person's judgment, not a check against a reference set.
- The Accurate note in **Settings › Experimental** now says this instead of "Not tested yet", and gives the pack size the app shows (2.3 GB).
- The in-app download was run end to end with the Accurate pack (2.3 GB), including the checksum check.

## New

- **User guide** in English and Korean: [docs/manual.md](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.md) · [docs/manual.ko.md](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.ko.md). It covers installing, reading, translation, editing and exporting, settings, shortcuts and troubleshooting. The README links to it.
- The README links to [Panely for macOS](https://github.com/sejoung/Panely).

## For developers

- Korean output from `dotnet` (build, test and verify logs) is no longer garbled when you run `build.cmd`, `verify.cmd`, `release.cmd`, `install-local.cmd` or `uninstall-local.cmd` in a Korean console.
- `tools/manual-screenshots.ps1` regenerates the user guide's screenshots from a synthetic demo comic.

## Known limitations

- Translation is experimental. The small M2M100 model often gets short lines and idioms wrong, and quality hasn't been checked against a golden set.
- Accurate mode needs about 2 GB more memory than Fast. If memory is tight, use Fast.
- "Match Speech Level" isn't available on Windows yet.
- In the AI chat window, the prompt shows a balloon count of 0 until you click **Save as Text File…**. Save the file first, then copy the prompt.
- Not tested yet: Windows on ARM, 125/150% and mixed-DPI setups, high-contrast mode.
- Translation jobs in progress are lost when you quit (finished pages are kept).

## 한국어

Panely Windows 1.0의 패치 릴리스입니다. 언어팩 다운로드 진행률 표시를 고치고, **정확하게** 번역 방식의 측정 결과를 반영했으며, 사용 설명서를 추가했습니다.

### 내려받기

| 파일 | 대상 |
|---|---|
| `Panely-1.0.1-win-x64.zip` | 대부분의 Windows PC(Intel·AMD) |
| `Panely-1.0.1-win-arm64.zip` | ARM 기반 Windows. **실제 ARM 기기에서는 아직 실행해 보지 않았습니다.** 실행 결과를 알려 주세요 |

ZIP을 폴더에 풀고 `Panely.exe`를 실행합니다. 설치 프로그램, 관리자 권한, .NET 설치가 필요 없습니다. 체크섬은 `SHA256SUMS.txt`에 있습니다.

**1.0.0에서 업데이트**: Panely를 닫고 폴더 내용을 이 ZIP으로 바꿉니다. 라이브러리, 읽던 위치, 고친 번역, 언어팩은 그대로 남습니다.

코드 서명이 없어 처음 실행할 때 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다. **추가 정보 › 실행**을 누르세요.

### 고친 것

- **언어팩 다운로드 진행률이 받는 동안 바로 갱신됩니다.** 전에는 **설정 › 실험적 기능**에서 다른 탭에 갔다 와야 퍼센트가 바뀌었습니다.
- **번역 패널이 모든 언어팩을 받는 동안 다운로드 중으로 표시됩니다.** 전에는 처음 설치할 때 번역·말풍선 탐지 팩(약 770MB)을 받는 동안 패널이 멈춘 것처럼 보이고, 다운로드 버튼이 다시 나타났습니다.

### 바뀐 것

- **정확하게 번역 방식을 측정했습니다.** 말풍선 146개인 298쪽 일본어 웹툰 기준, 책 전체가 **빠르게**보다 약 7초 더 걸렸고 최대 메모리를 약 2GB 더 썼습니다(5.8GB 대 3.5GB). 나란히 비교해 본 결과 번역은 **빠르게**보다 훨씬 나았습니다. 한 사람의 평가이며 기준 번역으로 검수한 결과는 아닙니다.
- **설정 › 실험적 기능**의 **정확하게** 안내가 "아직 검증하지 않았습니다" 대신 위 내용을 알려 주고, 앱에 표시되는 언어팩 크기(2.3GB)로 맞췄습니다.
- 앱 안에서 언어팩을 끝까지 내려받는 과정을 **정확하게** 팩(2.3GB)으로 체크섬 검증까지 확인했습니다.

### 알려진 제약

- 번역은 실험 기능입니다. 작은 M2M100 모델이라 짧은 대사와 관용 표현을 자주 틀리며, 골든 세트로 품질을 검수하지 않았습니다.
- **정확하게**는 **빠르게**보다 메모리를 약 2GB 더 씁니다. 메모리가 넉넉하지 않으면 **빠르게**를 쓰세요.
- 말투 맞춤은 Windows에서 아직 쓸 수 없습니다.
- AI 채팅 창의 안내문은 **텍스트 파일로 저장…**을 누르기 전에는 말풍선 수를 0으로 표시합니다. 파일을 먼저 저장한 뒤 안내문을 복사하세요.
- 아직 확인하지 않은 환경: ARM 기반 Windows, 125/150% 및 혼합 DPI, 고대비 모드.
- 진행 중인 번역 작업은 앱을 종료하면 사라집니다(완료한 쪽은 남습니다).
