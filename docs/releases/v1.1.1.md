Panely for Windows 1.1.1 fixes two problems in Edit Balloons. When you drag over text the translation missed, numbers next to the text are no longer dropped. The edit bar now updates as soon as you change a balloon. The user guide now covers balloon editing in full, plus other features it didn't describe before.

**English** · [한국어](#한국어)

## Download

| File | For |
|---|---|
| `Panely-1.1.1-win-x64.zip` | Most Windows PCs (Intel and AMD) |
| `Panely-1.1.1-win-arm64.zip` | Windows on ARM. **Not run on an ARM device yet**, and translation runs on the CPU only. Please report what you see |

Extract the ZIP to a folder and run `Panely.exe`. No installer, administrator rights or .NET install are needed. Checksums are in `SHA256SUMS.txt`.

**Updating from 1.1.0**: close Panely and replace the folder's contents with this ZIP. Your library, reading positions, translations, edits and language packs are kept. You don't need to download anything again or translate anything again.

**Updating from 1.0.x**: see the [1.1.0 notes](https://github.com/sejoung/PanelyWindows/releases/tag/v1.1.0). The translation model changed in 1.1, so books translated with 1.0.x need translating again.

The app isn't code-signed, so SmartScreen may say "Windows protected your PC" on first launch: choose **More info › Run anyway**.

## Fixed

- **Adding a balloon keeps numbers.** In **Edit Balloons**, you can drag over text the translation missed to add a balloon. Pieces with only numbers were thrown away as noise. A sign reading "LUNA 12" was read as "LUNA" and translated as "루나"; it's now read as "LUNA 12" and translated as "루나 12".
  - Pieces on the same line are joined in reading order. Before, side-by-side pieces could come out in the wrong order.
  - This applies only to areas you drag over or add with **Add a Balloon Here…**. Translating a whole page still drops lone numbers such as page numbers.
  - Pieces with only symbols (such as "!!" or "...") are still dropped.
- **The edit bar updates right away.** When you added, edited, hid or brought back a balloon, the edit bar didn't change. Its count ("1 edited", "1 Hidden") stayed the same, **Revert This Book…** stayed off, and **Show All Hidden Balloons** didn't appear. You had to turn edit mode off and on again to see the change.

## User guide

The [user guide](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.md) ([한국어](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.ko.md)) was checked against the app, and the gaps were filled.

- **Edit Balloons is described in full**, with new screenshots. Topics:
  - what the popover shows, and what each status message means
  - adding a balloon over text the translation missed, by dragging or with **Add a Balloon Here…**
  - what to do when no text can be read
  - fixing the original text, which translates it again into every language the book already has
  - hidden balloons, **Revert This Book…** and translating again
- **Newly described**:
  - the five supported languages
  - exporting a whole series
  - the **⋯** menu for each language and the gear menu in the translation panel
  - Windows text recognition as a fallback when a recognition pack is missing
  - **Clear Translation Cache**, which also stops running translations
  - the page's right-click menu
  - **Cancel** while a book is loading
  - touchscreens and horizontal wheels
  - more ways to remove bookmarks
  - the Edit, Window and Help menus
- **Corrected**:
  - The Jobs window has **Cancel Export** (not **Stop**) for running exports, and **Open This Book** for other books' jobs.
  - Fit and zoom shortcuts also work on the numeric keypad.
  - `Ctrl+[` and `Ctrl+]` also move between volumes.
  - The menu bar holds most commands, not all of them.

## For developers

- `tools/manual-screenshots.ps1` also captures the drag-to-add-a-balloon screens (`add-balloon-drag`, `add-balloon`). It drags with the real mouse, only inside the Panely window. Each screen now starts with no saved balloon edits, so edits from one screen don't show up in the next.
- The README badges now show the latest release, downloads, CI status and llama.cpp (Vulkan).

## Known limitations

- Translation is experimental and makes mistakes, especially when text recognition misreads the original. Quality hasn't been checked against a golden set.
- **Without a usable GPU, translation is several times slower.** Windows on ARM always translates on the CPU.
- In the AI chat window, the prompt shows a balloon count of 0 until you click **Save as Text File…**. Save the file first, then copy the prompt.
- Not tested yet: Windows on ARM, 125/150% and mixed-DPI setups, high-contrast mode.
- Translation jobs in progress are lost when you quit (finished pages are kept).

## 한국어

Panely Windows 1.1.1은 말풍선 편집의 문제 두 가지를 고칩니다. 번역되지 않은 글자를 끌어서 말풍선을 추가할 때, 글자 옆의 숫자가 더 이상 빠지지 않습니다. 말풍선을 고치면 편집 막대도 바로 바뀝니다. 사용 설명서는 말풍선 편집을 빠짐없이 설명하도록 보강했고, 그동안 설명하지 않던 다른 기능도 넣었습니다.

### 내려받기

| 파일 | 대상 |
|---|---|
| `Panely-1.1.1-win-x64.zip` | 대부분의 Windows PC(Intel·AMD) |
| `Panely-1.1.1-win-arm64.zip` | ARM 기반 Windows. **실제 ARM 기기에서는 아직 실행해 보지 않았고**, 번역은 CPU로만 돕니다. 실행 결과를 알려 주세요 |

ZIP을 폴더에 풀고 `Panely.exe`를 실행합니다. 설치 프로그램, 관리자 권한, .NET 설치가 필요 없습니다. 체크섬은 `SHA256SUMS.txt`에 있습니다.

**1.1.0에서 업데이트**: Panely를 닫고 폴더 내용을 이 ZIP으로 바꿉니다. 라이브러리, 읽던 위치, 번역 결과, 고친 내용, 언어팩은 그대로 남습니다. 다시 받거나 다시 번역할 것은 없습니다.

**1.0.x에서 업데이트**: [1.1.0 릴리스 노트](https://github.com/sejoung/PanelyWindows/releases/tag/v1.1.0)를 보세요. 1.1에서 번역 모델이 바뀌어 1.0.x에서 번역한 책은 다시 번역해야 합니다.

코드 서명이 없어 처음 실행할 때 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다. **추가 정보 › 실행**을 누르세요.

### 고친 것

- **말풍선을 추가할 때 숫자가 빠지지 않습니다.** **말풍선 편집**에서는 번역되지 않은 글자를 끌어서 말풍선을 추가할 수 있습니다. 이때 숫자만 있는 조각을 잡음으로 보고 버렸습니다. 표지판 "LUNA 12"는 "LUNA"로 읽혀 "루나"로 번역됐는데, 이제 "LUNA 12"로 읽어 "루나 12"로 번역합니다.
  - 같은 줄에 나란히 놓인 조각은 읽는 순서대로 이어 붙입니다. 전에는 나란히 놓인 조각의 순서가 뒤바뀔 수 있었습니다.
  - 끌어서 지정한 영역과 **여기에 말풍선 추가…**로 잡은 영역에만 적용됩니다. 페이지 전체를 번역할 때는 쪽 번호처럼 숫자만 있는 조각을 지금처럼 걸러 냅니다.
  - "!!", "..."처럼 기호만 있는 조각은 여전히 버립니다.
- **편집 막대가 바로 바뀝니다.** 말풍선을 추가하거나 고치거나 숨기거나 다시 보이게 해도 편집 막대가 그대로였습니다. "고친 말풍선 N개", "숨김 N개" 수가 바뀌지 않았고, **이 책 되돌리기…**는 꺼진 채였고 **숨긴 말풍선 모두 보이기**는 나타나지 않았습니다. 편집 모드를 껐다 켜야 반영됐습니다.

### 사용 설명서

[사용 설명서](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.ko.md)([English](https://github.com/sejoung/PanelyWindows/blob/main/docs/manual.md))를 앱과 하나하나 대조해 빠진 내용을 채웠습니다.

- **말풍선 편집을 빠짐없이 설명합니다.** 새 스크린샷도 넣었습니다. 다루는 내용:
  - 팝오버에 나오는 내용과 상태 문구가 각각 무슨 뜻인지
  - 인식되지 않은 글자에 말풍선 추가하기(끌기, **여기에 말풍선 추가…**)
  - 글자를 읽지 못했을 때 할 일
  - 원문 고치기(이미 번역해 둔 모든 언어로 다시 번역합니다)
  - 숨긴 말풍선, **이 책 되돌리기…**, 다시 번역하기
- **새로 설명한 기능**:
  - 지원 언어 5개
  - 시리즈 전체 내보내기
  - 번역 패널의 언어별 **⋯** 메뉴와 톱니바퀴 메뉴
  - 글자 인식 팩이 없을 때 Windows 글자 인식으로 대신 읽는 동작
  - **번역 캐시 지우기**(진행 중인 번역도 멈춥니다)
  - 페이지 오른쪽 클릭 메뉴
  - 책을 여는 중 **취소**
  - 터치스크린과 가로 휠
  - 북마크를 지우는 다른 방법들
  - 편집·창·도움말 메뉴
- **바로잡은 내용**:
  - 작업 창에서 진행 중인 내보내기의 버튼은 **중지**가 아니라 **내보내기 취소**이고, 다른 책의 작업에는 **이 책 열기**가 있습니다.
  - 맞춤·확대 단축키는 숫자 키패드로도 됩니다.
  - `Ctrl+[`, `Ctrl+]`로도 앞뒤 권으로 갑니다.
  - 메뉴 막대에는 모든 명령이 아니라 대부분의 명령이 있습니다.

### 개발자용

- `tools/manual-screenshots.ps1`이 끌어서 말풍선 추가하는 화면(`add-balloon-drag`, `add-balloon`)도 찍습니다. 실제 마우스로 끌되, Panely 창 안에서만 끕니다. 화면마다 저장된 말풍선 수정 기록을 지우고 시작하므로, 앞 화면에서 고친 내용이 다음 화면에 남지 않습니다.
- README 배지에 최신 릴리스, 다운로드 수, CI 상태, llama.cpp(Vulkan)를 표시합니다.

### 알려진 제약

- 번역은 실험 기능이라 틀릴 때가 있고, 특히 글자 인식이 원문을 잘못 읽으면 번역도 틀립니다. 골든 세트로 품질을 검수하지 않았습니다.
- **쓸 수 있는 GPU가 없으면 번역이 몇 배 느립니다.** ARM 기반 Windows는 항상 CPU로 번역합니다.
- AI 채팅 창의 안내문은 **텍스트 파일로 저장…**을 누르기 전에는 말풍선 수를 0으로 표시합니다. 파일을 먼저 저장한 뒤 안내문을 복사하세요.
- 아직 확인하지 않은 환경: ARM 기반 Windows, 125/150% 및 혼합 DPI, 고대비 모드.
- 진행 중인 번역 작업은 앱을 종료하면 사라집니다(완료한 쪽은 남습니다).
